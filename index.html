Revisión estática del código · 28 de septiembre de 2026 · 81 fichas humanas

Qué es: un manual para cualquier persona que use el bot, no una certificación de producción. No se envió ningún mensaje, no se pulsó ningún botón real y no se ejecutaron las pruebas al prepararlo.

Cómo leer: empieza en la sección A. Cada ficha indica si la entrada es por texto o voz. Cada instrucción ocupa su propio renglón; junto a cada paso que requiere escribir verás el comando azul y su botón Copiar. Las comillas son solo visuales y no se copian. Los formatos entre corchetes exigen datos reales y autorización y no ofrecen botón de copia. Para una instrucción de voz se usa el micrófono de Telegram, no el botón Copiar.

Seguridad: casi todos los botones de AYUDA abren fichas; la excepción verificada es «INFORMES MAESTROS», que consulta y envía la lista sin escribir. Los botones APROBAR, TAREA, LOGRO y ACK fuera de AYUDA sí pueden tener efectos. No ejecutar escrituras, llamadas, publicaciones, misiones, subidas, borrados ni aprobaciones sin orden expresa.

Prefijos reales: usa INFORMES MAESTROS [N] para listar; INFORME MAESTRO [contenido] para registrar; YARBIS [consulta] para consultar. VOZ escrito se enruta como alias YARBIS y no garantiza audio para consultas de informes.

Alcance: 2 en A · 79 en B. Cada uno de los 79 botones del menú tiene sus propios pasos y explicación. No se ha copiado el número 408 de una aplicación diferente.

Fuente: menú AYUDA y rutas de Telegram del API Server local. Un webhook de Make u otra app requiere comprobación independiente; una frase del bot no equivale a éxito externo.
